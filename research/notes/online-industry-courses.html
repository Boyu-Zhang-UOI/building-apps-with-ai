Online, Industry, MOOC, Bootcamp and Cohort Courses on Vibe Coding and AI-Assisted Coding (2025 to Sept 2026) ​

Research date: 2026-09-25. All pages were accessed on that date. "Page date" means the date shown on the source. Where a page carried no date, it is marked "undated (live page Sept 2026)". Some catalog pages (Coursera, Skilljar) change often, so their module lists reflect the September 2026 state and may not match earlier versions.

Q1. DeepLearning.AI short courses (Vibe Coding 101 with Replit, Claude Code, Build with Andrew, others) and Andrew Ng's views on teaching everyone to code with AI ​

Takeaway ​

DeepLearning.AI (DLAI) short courses are 1–2 hour video courses of 7–17 lessons. Each lesson runs 1–26 minutes and centers on one or two worked projects, and every course ends in a 7–10 minute graded quiz. The courses are free to audit, and a certificate requires a Pro membership. The line runs from the beginner Replit course (Mar 2025) to the intermediate Claude Code course (Aug 2025), then to a true zero-experience course, "Build with Andrew" (Jan 2026, any chatbot, birthday-card app plus table-tennis game), and a spec-driven development course (2026). Andrew Ng's position over this period: everyone should build with AI now (Nov 2025, Jan 2026), but "vibe coding" is a misleading name for hard intellectual work (Jun 2025), and software fundamentals still separate strong builders from weak ones (Aug–Sept 2026).

Cited Findings ​

Vibe Coding 101 with Replit (DLAI x Replit)

  • Announced by Andrew Ng on Mar 26, 2025. Taught by Michele Catasta (President, Replit) and Matt Palmer (Head of DevRel, Replit). — Andrew Ng on X, Mar 2025; LinkedIn post
  • Level Beginner, 1 h 34 min, 7 video lessons plus a graded quiz. Lessons: 1) Introduction (3m); 2) Principles of Agentic Code Development (18m); 3) Planning and Building an SEO Analyzer (23m); 4) Implementing SEO Analysis Features (12m); 5) Planning and Building a Voting App (26m); 6) Enhancing the National Parks Voting App (7m); 7) Next Steps and Best Practices (4m); Quiz (10m, graded). — DLAI course page, undated (live page Sept 2026)
  • Projects: a website SEO/performance analyzer and a national-parks ranking/voting app. Tool: Replit (cloud IDE, package manager, deployment). The course is labeled "Beginner", yet the page recommends "some coding experience" and background in prompting LLMs. Free "during platform beta"; certificate with a PRO membership. — DLAI course page
  • Principles taught, as summarized in launch coverage: be precise, give the agent one task at a time, write specific prompts, keep projects tidy, start fresh sessions for each new feature, and debug systematically. Coverage also frames five skills: thinking, frameworks, checkpoints, debugging, context. (This comes from search-result summaries of launch coverage and was not verified word-for-word on the primary page.) — Andrew Ng LinkedIn launch post
  • One learner (an SRE at GMO Media) wrote that pasting error messages and code status back to the agent "quickly" produced causes and fixes, and found this approach understandable for beginners. — DEV Community learner write-up, 2025

Claude Code: A Highly Agentic Coding Assistant (DLAI x Anthropic)

  • Announced Aug 6, 2025. Taught by Elie Schoppik, Head of Technical Education at Anthropic. — Andrew Ng on X, Aug 2025; DLAI community announcement
  • Level Intermediate, about 2 h, 10 video lessons plus a quiz and readings. Lessons: Introduction (4m); What is Claude Code? (8m); Course Notes (reading); Setup & Codebase Understanding (13m); Adding Features (17m); Testing, Error Debugging and Code Refactoring (12m); Adding Multiple Features Simultaneously (11m); Exploring Github Integration & Hooks (10m); Refactoring a Jupyter Notebook & Creating a Dashboard (12m); Creating Web App based on a Figma Mockup (9m); Conclusion (1m); Quiz (7m graded); Prompts & Summaries of Lessons (reading). — DLAI course page, undated (live Sept 2026)
  • Three worked projects: exploring and extending a RAG chatbot codebase; refactoring an e-commerce data-analysis Jupyter notebook into a dashboard; building a web app from a Figma mockup. Tools: Claude Code, MCP servers (Playwright, Figma), Git/GitHub, Jupyter. Prerequisites: Python and Git. Free during a "limited-time beta"; certificate requires Pro. — DLAI course page
  • In late Dec 2025 Andrew was still promoting it as "the best way to learn to use it well." — Andrew Ng on X

Build with Andrew (zero-experience course)

  • The Batch letter of Jan 9, 2026 introduced it. The course is for "marketers, product professionals, operations specialists, analysts, students" and anyone who has never coded. Andrew cites a widening productivity gap between people who can and cannot code. The course is vendor-agnostic: learners can use ChatGPT, Gemini, Claude or DLAI's built-in chatbot. The letter promises that learners build an app in "less than 30 minutes." — The Batch, "Build with Andrew!", Jan 9, 2026
  • Course page: Beginner, about 1 h total, and it "assumes no prior knowledge of AI or coding." Lessons: Creating an app with AI (2m); Telling AI what you want (10m) plus a [chatbot] practice version (5m); Download and open your app (2m); Customize your app (6m) plus [chatbot] (5m); Now you can build more apps (2m) plus [chatbot] (5m); You're a builder now! (3m); Build your final project [chatbot] (15m); Submit your final project (2m); Course Quiz (10m); More DLAI courses to try! (2m). Projects: a birthday message generator, then a table tennis game built with the same process, then a learner-chosen final project. Certificate requires Pro ($25/mo billed annually or $30/mo monthly). — DLAI Build with Andrew page, live Sept 2026
  • Note: the letter says "less than 30 minutes", and the course page lists about 1 hour including quiz and final project. The two figures are consistent (build time vs. total course time).

Spec-Driven Development with Coding Agents (DLAI x JetBrains)

  • Beginner, 1 h 16 min. Lessons: Introduction (4m); Why spec-driven development? (4m); Workflow overview (3m); Set up your environment (reading); Setup (1m); Creating the constitution (5m); Feature specification (3m); Feature implementation (1m); Feature validation (4m); Project replanning (6m); The second feature phase (6m); The MVP (3m); Legacy support (4m); Build your own workflow (6m); Agent replaceability (3m); Conclusion (1m); Quiz (10m). Recommended background: familiarity with a programming language and experience with LLM-based coding tools. Page lists the instructor as Paul Everitt (JetBrains). — DLAI course page, live Sept 2026
  • Secondary coverage dates the announcement to Apr 15, 2026. One search-result summary named a different instructor (Sandeep Dinesh) and dated it "late 2025". The primary page (Paul Everitt) is taken as authoritative. — Blockchain.news, 2026
  • Workflow: write a markdown "constitution" and feature specs, then let the agent implement. The course presents this as the disciplined alternative to vibe coding, and the tooling works with Claude Code, GitHub Copilot, Cursor, Codex CLI, Gemini CLI, opencode, Windsurf and Qwen Code. — DLAI course page

Andrew Ng's views (dated)

  • May/June 2025: at LangChain Interrupt, Ng objected to the term "vibe coding" because it suggests engineers "go with the vibes". He called guiding AI to write software "a deeply intellectual exercise" and said he finds a day of it exhausting. — Hacker News thread, Jun 2025; Wikipedia: Vibe coding
  • Nov 2025, at Snowflake Build: Ng recommended that "everyone" learn to code and said "Don't code by hand... Get AI to help you to code." Critics quoted by IT Pro: Tal Zarfati (JFrog) on supply-chain risks such as slopsquatting; Chrissa Constantine (Black Duck), who warned overreliance "can lead to shallow learning, fragile codebases, and security risks." IT Pro also cites a Fastly finding that 67% of developers spend more time debugging AI-generated code. — IT Pro, Nov 14, 2025; Entrepreneur
  • Jan 2026: "It is now time for everyone... to build software applications with AI!" — The Batch, Jan 9, 2026
  • Aug 28, 2026 (AI Engineering Skills Map, Part 3): fundamentals remain essential even when agents write all the code. Without them, builders make poor tradeoffs in "latency, availability, consistency, reliability, maintainability, simplicity, and/or cost" without knowing it. The five fundamentals he lists: building full-stack applications, managing data, designing system architectures, making systems secure and reliable, scaling and operating in production. His phrasing: developers who deeply understand how software works "vastly outperform those who vibe code without understanding." — The Batch, Aug 28, 2026
  • Sept 2026 Skills Map top level: (i) building and deploying AI applications, (ii) software engineering fundamentals, (iii) using coding agents, (iv) shaping the build. — The Batch, AI Engineering Skills Map, 2026
  • 2026: Ng also wrote a letter on "loop engineering" (nested feedback loops for coding agents) as the skill replacing manual prompt writing. The exact date was not captured. — Andrew Ng on X

Inferences ​

  • The DLAI format fits an 8-week course well as per-week pre-work: a 1–2 h video block with a single worked project, then a live or lab session. Build with Andrew's structure (explain → try in chatbot → download/open → customize → second app → own final project → submit) is a ready template for Week 1.
  • Ng's shift from "everyone build now" (Jan 2026) to "fundamentals still matter" (Aug 2026) supports putting light fundamentals in later weeks: data, security, deployment and architecture explained in plain language, with no syntax drills.
  • "Beginner" labels are unreliable. Vibe Coding 101 with Replit is marked Beginner but assumes some coding. Build with Andrew is the only DLAI course here designed for true non-coders.

Gaps ​

  • No DLAI course page gives a formal publication date. Dates come from X/LinkedIn announcements and The Batch.
  • Whether "free during beta" still applies to the Replit and Claude Code courses as of Sept 2026 is unclear; the pages still say "free... beta".
  • Found no aggregated learner-review data (ratings) for DLAI short courses.
  • Did not verify whether Replit's free Starter plan is enough to finish Vibe Coding 101 in 2026.

Q2. Vendor and platform academies: Anthropic, OpenAI, Google/Kaggle, Microsoft/GitHub, Replit, Lovable, Cursor ​

Takeaway ​

Vendor academies are free, short and tool-specific. They mostly assume some developer background (terminal, Git). The main exceptions are Replit Learn, Lovable Academy, Google's "Vibe Coding for Beginners" and the Kaggle intensive, which are explicitly pitched at non-developers. Free-tier fit varies a lot. GitHub Copilot courses work on Copilot Free, and Google AI Studio and Kaggle work on free Google accounts. Anthropic's Claude Code courses need a paid Claude plan or API key.

Cited Findings ​

Prerequisites: basic command line and editor familiarity, plus a Claude Pro, Max or Enterprise account or an API key. So a free Claude account is not enough. Free registration; certificate on completion. — Skilljar: Claude Code 101
  • Claude Code in Action (current version) is positioned for developers who already use Claude Code and want "long, hands-off" sessions. Sections: Steering Long Sessions; A CLAUDE.md That Follows; Verification Skills; Permission Modes; Hooks; Routines and Headless; GitHub Actions and Code Review; Trust It: Verifying Unsupervised Runs; Plugins; Course Quiz. Free. — Skilljar: Claude Code in Action

  • Kaggle x Google "5-Day AI Agents: Intensive Vibe Coding Course", Jun 15–19, 2026, free. The previous (Nov 2025) edition reached more than 1.5 million learners. — Google blog, Apr 27, 2026; EdTech Innovation Hub, 2026

  • Replit Learn (free): "AI Foundations" (30 min, 7 lessons: communicating with AI, shaping app ideas, using Replit) and "Enterprise Foundations" (30 min, 6 lessons). Coming soon: "Intro to Replit" (45 min, 5 lessons) and "Advanced Vibes" (30 min, 5 lessons). — Replit Learn, live Sept 2026

  • Cursor's official course teaches developers "how to use AI to be more effective as a programmer." Inferences ​

  • The best "free-tier-safe" vendor materials for a beginner course: Build with Andrew (any chatbot), Google AI Studio codelab (skip the Cloud Run step), Kaggle intensive (free accounts), GitHub Copilot CLI for Beginners and MS Learn Copilot modules (Copilot Free), Replit Learn, Lovable Academy videos, and Cursor Learn's conceptual lessons (tokens, context, hallucinations), which are tool-agnostic reading.
  • Anthropic's Claude Code courses are high quality but paywalled at the tool level (Pro or higher). They fit an "optional, basic-paid-tier" track rather than core weeks.
  • Vendor curricula have converged on the same late-2025/2026 concept set: context files (CLAUDE.md, instructions files), skills, subagents, MCP, hooks, headless and CI use, verification. For true beginners, only context files and verification are likely relevant.

Gaps ​

  • GitHub Skills (skills.github.com) Copilot exercises were not fetched; module list unknown.
  • OpenAI Academy Codex page returned 403. Formats, durations and the ChatGPT plan needed for Codex (Free vs Plus) are not verified.
  • Replit free-tier limits for Agent usage in 2026 were not verified.
  • Anthropic's Skilljar pages give no durations or dates. The original 2025 "Claude Code in Action" syllabus has since been replaced, and the earlier version was not captured.
  • Kaggle Learn guide content (per-day codelab titles) did not render in the fetcher.

Q3. MOOC and marketplace courses: Coursera (Vanderbilt/Jules White, Scrimba, Google, CU), Codecademy, Scrimba, DataCamp, Udemy, Zero to Mastery, freeCodeCamp, edX ​

Takeaway ​

MOOC platforms carry dozens of short (1–9 h) vibe-coding courses. The most substantial are Vanderbilt/Jules White's Coursera line (Claude Code for developers, and "Build Anything with AI — No Code Required" for non-coders), Scrimba's 5-course "Vibe Coding Essentials" (about 15 h, beginners), and paid bootcamp-style video courses such as Zero to Mastery's 18-hour "Vibe Coding Bootcamp" (8 projects, multi-model, $299). Ratings are generally high (4.4–4.8), but critical reviews repeat the same complaints: too superficial, lecture-heavy, jargon unexplained for non-coders, and paid tool subscriptions needed.

Q4. Cohort-based, live and bootcamp-style programs: Maven, Campus x Replit, fast.ai/Answer.AI Solveit, O'Reilly/Addy Osmani ​

Takeaway ​

Live cohorts run 3–8 weeks with about 3–5 h/week of combined live sessions, async lessons and tiered homework. Prices range from free events to $1,500 tuition. The one program found with the same shape as the planned course is Campus x Replit "VibeCoding 101": 8 weeks, one live class a week, 4 working apps plus a landing-page portfolio and a flagship project, aimed at non-technical professionals, $1,500. For developers, cohort offerings stress vendor-agnostic "agentic engineering" (context engineering, specs, review, CI) over tool demos. fast.ai's Solveit takes the opposite approach to vibe coding: small-step "dialog engineering."

Q5. Common patterns: projects built, progression, time per module, handling learners who have never coded ​

Takeaway ​

Beginner courses almost always start with a single-file browser app: a birthday or greeting card, a joke or compliment generator, a small game, or a landing page. They then repeat the same process on a second, slightly harder app, then add persistence, auth, or an API, and finish with deployment and a capstone or portfolio. Short-course lessons run 2–26 minutes. MOOC modules run about 1–2 h. Cohort weeks run about 3–5 h. Courses handle never-coders by removing setup (browser IDEs, chatbots that output one HTML file), teaching a repeatable describe → generate → run → customize loop, and framing the learner as a "director." Reviews show that jargon still trips non-coders.

Sequencing patterns (as documented)

  • Principles first, then project A (plan, then build), then enhance A, then project B (plan, then build), then enhance B, then best practices and next steps. — DLAI Vibe Coding 101

  • One running project extended through all chapters: quick start → context → workflows → custom agents → skills → MCP → capstone. — GitHub Copilot CLI for Beginners

  • Spec-first progression: constitution → feature spec → implement → validate → replan → second feature → MVP → legacy code → build your own workflow. — DLAI Spec-Driven Development
  • ZTM framing: "Becoming a Director", then choose an AI partner, then setup, with each mini-project done in a different chatbot (Claude, Gemini, ChatGPT) before moving to AI code editors, MCP and open-source local models. — ZTM

Handling never-coders

  • Zero-prerequisite framing plus any chatbot plus a downloadable app. Build with Andrew "assumes no prior knowledge of AI or coding" and lets learners use ChatGPT, Gemini, Claude or a built-in chatbot. — DLAI; The Batch
  • Browser-based stacks such as Replit remove setup friction. Coverage describes going from a blank screen to a live, shareable app in hours. — Replit blog; Replit Learn
  • Audience targeting by role: Scrimba names marketers, designers and accountants; Campus names PMs, operations and customer success; Build with Andrew names marketers and analysts. — Coursera Scrimba; Campus; The Batch
  • Non-code-first projects built on the learner's own data (files, bank statements, folders) instead of software-engineering exercises. — Coursera Build Anything

Inferences ​

  • A defensible 8-week arc drawn from these patterns:
    1. One-file browser app via chatbot (Build with Andrew style).
    2. Second app with the same loop, plus "director" and prompting skills.
    3. Browser IDE / agent (AI Studio, Replit, Lovable) and a multi-feature app.
    4. Debugging and reading errors.
    5. Data and persistence (DB or file) and personal-data projects.
    6. Git/GitHub, deployment and a portfolio landing page.
    7. Context files, specs and security basics.
    8. Capstone plus demo.
  • Two apps per course, using the same method on a second, different project, is nearly universal. It teaches that the process transfers, which matters more than any tool's interface.
  • Games (table tennis, Snake, whack-a-mole, reaction game, card game) are the most common "second project" because they give instant visual feedback and need no backend. Forms, trackers and dashboards are the common "useful" projects.

Q6. Delivery elements praised or criticized (tool-specificity, shallowness, obsolescence, missing fundamentals) ​

Takeaway ​

Praise goes to short, clear, hands-on courses that let beginners ship something quickly and to instructors who explain plainly. Criticism clusters around five issues:

  • "super basic / superficial / all talking" courses.
  • Hands-on exercises that break because the tool changed.
  • Hidden costs from required paid subscriptions and API credits.
  • Unexplained jargon for non-coders.
  • A broader worry that vibe coding without fundamentals produces shallow learning, insecure code and learners who can't debug.

Cited Findings ​

  • Praised: "An empowering course- I never thought I could prompt engineer AI to build software" and "just the right balance of instruction and exercises" (Jules White Claude Code, 2025). — Coursera reviews
  • Criticized as shallow or lecture-heavy: "Very superficial. All talking, no hands on assignments" (Apr 2026); "Needs more basics and hands on guidance with screenshare, and less high level benefits" (Feb 2026). — Coursera reviews
  • Criticized for breakage and cost: a learner following exact exercise instructions got "errors all over the place" and flagged required Claude subscription and credit costs (Aug 2025). — Coursera reviews
  • "Super basic" (CU Vibe Coding Fundamentals, Nov 2025). Positive reviews say learners can now build apps without coding knowledge, and critical ones say non-programmers struggle with unexplained terms. — Coursera CU reviews
  • Rating spread as a signal: Codecademy's Lovable intro sits at 3.98/5 with 26% three-star ratings, while its Cursor-based "Intro to Vibe Coding" sits at 4.54/5. Scrimba's 5-course specialization is 4.4/5 with about 8.5% at 1–2 stars. — Codecademy Lovable; Codecademy Intro; Coursera Scrimba
  • Obsolescence: vibe coding tools change "every few months", so a course recorded a year ago may show an interface that no longer exists (blog-level source). — VibeGym blog, 2026
  • Providers respond to obsolescence by revising the Elite AI Assisted Coding curriculum quarterly and refreshing materials each cohort. Anthropic's "Claude Code in Action" has been re-scoped around 2026 features (routines/headless, plugins, verification). — Maven listing; Skilljar
  • Learning risks (opinion pieces): beginners stop reading error messages because they paste them into AI; they can't decompose problems when the AI fails ("prompt-dependent learners"); and a hybrid of structured study plus vibe-coded projects is recommended. — Skorykh blog, 2026; DEV: "Vibe Coding Is Fun — But It Might Be Quietly Ruining Your Learning Journey"
  • The same blog genre cites a "2025 Purdue study" finding ChatGPT code vulnerable in 40% of cases. This looks like a misattribution (the widely cited ~40% figure comes from the 2021 NYU "Asleep at the Keyboard" Copilot study). Do not use it without checking the primary source. — VibeGym blog
  • Industry critics: "Overreliance on AI can lead to shallow learning, fragile codebases, and security risks" (Chrissa Constantine, Black Duck). Supply-chain risks such as slopsquatting and prompt injection (Tal Zarfati, JFrog). — IT Pro, Nov 2025
  • HN discussion of fast.ai's "Breaking the spell of vibe coding": skill-atrophy concerns and a view that classical design and architecture knowledge amplifies AI tools. — Hacker News
  • Counterpoint: an XDA writer reports that vibe coding taught them programming "better than any course", because textbook-first learning is slow to produce anything real. — XDA Developers
  • Andrew Ng's own caution: fundamentals let builders see tradeoffs (latency, reliability, cost). — The Batch, Aug 28, 2026

Inferences ​

  • Reviews reward hands-on, screen-shared, follow-along building over talk about benefits. An 8-week course should be mostly labs, with short concept segments.
  • To avoid "outdated quickly", teach a tool-agnostic loop (plan → prompt → run → read the error → verify → commit), keep tool-specific click paths in easily updated handouts rather than recorded video, and plan a per-term refresh.
  • Debugging, reading error messages, basic security (secrets, auth, input handling) and "explain this code back to me" exercises answer the most common critiques directly and match Ng's fundamentals argument.

Gaps ​

  • Found no Reddit threads with substantive learner reviews of specific courses (search returned none). HN coverage was about vibe coding broadly, not particular courses.
  • The Class Central review report (the main independent reviewer) could not be retrieved.
  • Found no controlled study of learning outcomes from vibe-coding courses.
