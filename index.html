Building Apps with AIBuild real software with AI, on a $0 budget.

A hands-on University of Idaho course for students from any major who have taken one programming course. You ship a deployed web app by directing AI tools, and learn the habits that make that software trustworthy. 3 credits · a 16-week semester · two 75-minute studios a week.

Very hands-on

Two 75-minute studios a week. Studio A is a short talk (15 minutes at most) and a lab; Studio B is a workshop with practice, project time and help. You ship five projects.

See the projects

Free tools only

Every required tool has a free tier, and every layer has two tested fallbacks for when free limits run out.

The tool handout

One workflow, every tool

The Safe Loop — describe, plan, step, test, read, commit — works in a chat window in week 1 and with an AI agent in weeks 11–16.

The Safe Loop

Graded on understanding, with support

Labs and timed builds are graded on effort, not polish or speed, and exit tickets aren't graded on correctness. Three short, friendly walkthroughs, with the questions published in advance, let you show what you understand. Walkthroughs 1 and 2 can be retaken.

What to expect

Safety built in

Nine plain-English safety rules, each taught when you need it, and a week 13 lab where you test your own database the way an attacker would, then lock it down.

The safety contract

Based on evidence

Designed from a review of 2025–26 university and industry courses, education research and real security incidents, updated in October 2026.

The Safe Loop ​

#StepWhat you do
1DescribeGoal, context, constraints, "done when". Write the check first
2PlanAsk for a plan, and edit it before any code is written
3StepOne small change at a time
4TestRun your check, the normal case and an edge case
5ReadRead the diff, and write a short teach-back of what changed and why
6CommitA git save point with a clear message

If two fixes in a row fail, stop, start a fresh chat and rewrite the prompt: the two-strikes rule. Printable card.

How to use this site ​

  • Students: start with the first-hour quick start before Studio 1. Each week, open the week's overview and read This week at a glance first: it lists what to do before Studio A, what each studio covers, what's due and the minimum to keep up. Keep troubleshooting and the glossary handy.
  • Self-paced learners: follow the self-paced path, which says what replaces each studio activity when you're working alone. When you're stuck, use tutor mode.
  • Screen reader or keyboard users: the accessibility guide covers every tool the course uses.
  • Instructors: instructor notes, answer keys and the instructor guide are in the course's private source repository. To teach the course, ask Boyu Zhang for access.
