Credits budget for the course ​

The course runs for a 16-week semester, so your GitHub Copilot use stretches across several monthly allowances. Plan your credits across weeks 6–16 instead of hoping they last.

  • Credits reset on the first of each calendar month, not when the course starts. A 16-week semester covers parts of four or five months, and the agent weeks (11–16) cross at least one reset, so note which reset dates fall inside them.
  • Weeks 1–5 use chat assistants, not Copilot, and week 6 uses app builders and then a chat assistant to start Project 1. Weeks 6–10 mostly use completions and Ask mode, which are light. Weeks 11–16 use agent mode, which uses far more credits per request. Save most of each month's allowance for those weeks.
  • Spend less per task: one task per chat, a fresh chat when a conversation gets long, small steps (the Safe Loop), and Ask mode when you only need an explanation. Check the usage meter (the Copilot icon in the status bar) at the start of each week.
  • When credits stop, chat and agent mode stop until the month resets. Copilot has no cheaper fallback model. Switch to the fallback in the stack table straight away: Antigravity (18+), or Cline or Kilo Code with a free Groq or OpenRouter key, in the editor; OpenCode with free models in the terminal. Tell your instructor, and see troubleshooting.
  • Students: apply for GitHub Education early. Copilot Student adds unlimited completions and its own monthly credit allowance.
